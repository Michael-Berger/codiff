# Migration history

The three existing SQL files predate Drizzle's journal. The snapshots in `meta/`
baseline the four Better Auth tables generated by Void, and the journal records
all three SQL files in their existing order. This lets `void db generate` check
future auth schema changes without recreating tables already in `0001_sharing.sql`.

The sharing tables and the `account.issuer` addition are maintained by the SQL
files. For another hand-written migration, use `void gen migration <name>` so
its journal entry and snapshot are created together, then edit the new SQL file.
